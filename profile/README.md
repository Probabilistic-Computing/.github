## Repository layout

This organization profile repository provides:

- `profile/README.md` — this landing page (regenerated by `scripts/export_papers_catalog.py`).
- `docs/index.html` — Interactive Paper Map (GitHub Pages).
- `docs/papers.json` — Machine-readable catalog metadata.
- `.github/workflows/deploy-pages.yml` — Pages deployment.

> Do **not** hand-edit `profile/README.md` or `docs/papers.json`. Refresh from the parent lab:
> `python3 scripts/export_papers_catalog.py`
